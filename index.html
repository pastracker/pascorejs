Four Pillars of PasCore

A unified API for networking, UI updates, reactive state management, and WYSIWYG editing.

1. PasCore.Net

Advanced networking & API module. Automatically manages JWT tokens, standardizes backend payload wrapping, and gracefully intercepts 401/403 errors to handle session expiries.

2. PasCore.UI

DOM utilities, elegant notifications, Modals, and Confirmation Dialogs. Generates native animated DOM elements instantly, providing a seamless feedback loop.

3. PasCore.State

The Alpine.js killer. A high-performance reactive engine powered by JS Proxies. Use pas-model, pas-text, pas-bind, pas-class, and pas-click for true data binding.

4. PasCore.Editor

Enterprise WYSIWYG integration. Provides a unified wrapper around SunEditor, configuring standard toolbar options instantly for content management systems.
