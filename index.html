PasCore Engine

An enterprise-grade, zero-dependency Vanilla JS framework designed specifically for the PasCore Admin Interface. It gracefully replaces Alpine.js and Axios, providing a unified API for networking, UI updates, reactive state, and WYSIWYG editing.

1 PasCore.Net

The Networking & API module. It handles HTTP requests, automatically manages JWT tokens, wraps payloads according to PasCore backend standards, and intercepts 401/403 errors to redirect unauthorized users to the login page.

Features

  • Standardized fetch wrapper.
  • Auto-injects Authorization: Bearer headers.
  • Wraps POST/PUT bodies in { payload: data }.
  • Guaranteed return structure: { success, data, message, status }.

Usage Example

// GET Request
const users = await PasCore.Net.get('/users');

// POST Request (Auto wrapped payload)
const res = await PasCore.Net.post('/users/create', { 
    name: 'John' 
});

if (res.success) {
    console.log(res.data);
}

2 PasCore.UI

DOM Utilities and Notifications. Provides an elegant, animated toast notification system out of the box, falling back to Alpine.js stores if configured, or generating native DOM elements instantly.

Try it out:

// Syntax
PasCore.UI.toast('success', 'Settings updated successfully!');
PasCore.UI.toast('error', 'Network error occurred.');

3 PasCore.State

The Alpine.js alternative. A lightweight reactive engine utilizing JavaScript Proxies. It binds your data model to the DOM and automatically updates elements when variables change.

Directives

  • pas-model="key" Two-way data binding for inputs.
  • pas-text="key" Renders text content dynamically.
  • pas-show="key" Toggles display (supports !key negation).
  • pas-click="method()" Binds click events to defined methods.

Initialization

const appState = PasCore.State.create(
    '#app', 
    { name: 'John Doe', isLoading: false }, // initial data
    {
        save: function(state, event) {
            state.isLoading = true;
            // API call...
        }
    }
);

4 PasCore.Editor

A seamless wrapper for integrating SunEditor (a robust WYSIWYG editor). It sets up the editor with a predefined toolbar tailored for enterprise content management. 

// Initializes editor on a textarea with ID 'content-editor'
const editor = PasCore.Editor.init(
    'content-editor', 
    '
Initial HTML content
', 
    (content) => { console.log("Content changed:", content); }
);
